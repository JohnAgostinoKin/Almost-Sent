bible-rate

Two modes. Rate lines reacts to real lines one at a time and downloads a ratings CSV — archival now, not read by lib/judge.js (its calibration is a hardcoded LOVED/BORED/HATED block since the v4 reset — see lib/judge.js's own comment). If you have an older bible.csv from before the reset, rename it bible/pre-reset-audit.csv and never feed it back in as calibration. Candidate audit (run npm run audit-prep first) shows every raw candidate for 25 inputs — lane, model, judge score, which one the judge actually picked — so you can tell a judge problem ("my favorite was in the pool, the judge picked another") from a generator problem ("none of them were funny") from a prompt problem ("crude candidates barely exist in the pool").

"too far" and "bad" are independent — a line can be shocking and excellent, or offensive and unfunny.
