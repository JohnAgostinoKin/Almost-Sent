bible-rate

Rate real lines love / forgettable / hate, with a short reason each. Downloads bible.csv — drop it at the repo root; lib/judge.js reads it automatically as taste-judge calibration examples (five loved, five hated, rotated per call — see lib/judge.js's own comment). Run npm run bible-prep first to generate a wide pool of real, displayed-quality lines (bible/lines.json) — load that file below to rate lines with their original context shown alongside them.
